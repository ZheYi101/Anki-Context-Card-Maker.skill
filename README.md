# Anki Context Card Maker

A multilingual Codex skill for turning real language input into Fushi-style Anki context cards. It accepts text, timed subtitles, audio, video, or a video URL and keeps the target language, translation language, deck, dictionary, TTS, ASR, and media processor configurable.

## What it produces

- A front containing the target term or phrase and a complete context sentence.
- A short answer giving the target's meaning in this sentence, available media and audio; broader dictionary senses and extra examples remain collapsed references.
- Audio references in the order **term audio → context audio**.
- A deterministic `InstanceKey`, so repeated runs update the same context while the same term in another sentence or source remains a separate card.
- A manifest that explicitly records missing subtitles, dictionaries, TTS, media processors, or other resources instead of fabricating them.
- `ready_for_import` and `quality_issues` distinguish usable cards from drafts. A supplied sentence absent from the source is unmatched; a missing contextual meaning stays a draft and is skipped on import, even if a dictionary entry exists.

English defaults to the top-level `English` deck; other languages use `Anki::<language>::Video`, `Anki::<language>::Audio`, or `Anki::<language>::Text` unless a deck is specified. The default neutral note type is `Anki Card Maker Context`. Existing review history is preserved; historical decks and note types are not migrated.

## Install

Clone this repository into the Codex skills directory. The skill folder itself keeps the standard name `anki-context-card-maker`; the `.skill` suffix belongs to this distributable repository name.

macOS / Linux:

```bash
mkdir -p "$HOME/.agents/skills"
git clone https://github.com/ZheYi101/Anki-Context-Card-Maker.skill.git "$HOME/.agents/skills/anki-context-card-maker"
```

Windows PowerShell:

```powershell
git clone https://github.com/ZheYi101/Anki-Context-Card-Maker.skill.git "$env:USERPROFILE\.agents\skills\anki-context-card-maker"
```

Or ask Codex's `$skill-installer` to install the repo-root skill from `ZheYi101/Anki-Context-Card-Maker.skill` using `--path . --name anki-context-card-maker --dest ~/.agents/skills`. It is available on your next turn; restart Codex if it does not appear. See [Learning Lab](https://github.com/ZheYi101/Learning-Lab.skill) to install the complete three-skill learning flow.

The scripts require Python 3.10+ and use the standard library. On macOS, use `python3` and forward-slash paths. For example, from the directory containing your source and lookups:

```bash
python3 "$HOME/.agents/skills/anki-context-card-maker/scripts/anki_cards.py" --text ./source.txt --lookups ./lookups.json --target-language en-US --output ./anki-output --dry-run
```

Run `scripts/anki_cards.py --dry-run` first, inspect `manifest.json`, and only then run without `--dry-run` after approving the candidates and ensuring AnkiConnect is available. See [references/input-protocol.md](references/input-protocol.md) for lookup JSON and command examples.

The default format practices meaning-in-context, not independent productive recall or listening-only comprehension. Select expressions relevant to the learner, keep one meaning target per card, and use a short contextual `definition`. See [card quality](references/card-quality.md). Existing instance keys, card fields, and scheduling identity are retained.

## Optional capabilities

yt-dlp, VideoCaptioner/Faster-Whisper, ffmpeg, TTS, and AnkiConnect are optional implementations, not hard dependencies. Reuse an existing equivalent tool or exported SRT/VTT when possible. The skill never silently installs software, uploads source media, or performs online dictionary queries while generating cards.

On macOS, configure capabilities using paths on the Mac. Text matching and previews do not require Windows tools. Video/audio processing can use an installed `ffmpeg`; provide existing SRT/VTT captions or subtitles generated by a configured local ASR tool. The legacy `--transcribe` adapter targets Faster-Whisper-XXL and is not a general macOS transcription command. The built-in automatic TTS uses Windows System.Speech; on macOS supply term pronunciation as a `word_audio` file in each lookup, or leave TTS unavailable. Missing optional audio is recorded in the manifest. Actual import requires desktop Anki with AnkiConnect running on the Mac.

## Offline dictionaries

The repository intentionally does not commit generated dictionary databases: ECDICT is larger than GitHub's regular file limit, and CC-CEDICT/JMdict carry their own distribution terms. Use the explicit installer when local dictionaries are needed:

```powershell
python .\scripts\install_dictionaries.py --provider ecdict
python .\scripts\install_dictionaries.py --provider cc-cedict
python .\scripts\install_dictionaries.py --provider jmdict
```

On macOS, run the same installer with `python3 "$HOME/.agents/skills/anki-context-card-maker/scripts/install_dictionaries.py" --provider <provider>`. Dictionary downloads happen only when you explicitly run this installer.

You can also provide a locally downloaded source file with `--source`. The installer records provider, source URL, SHA-256, installation time, and license notes in `scripts/data/dictionary-manifest.json`. Card generation itself remains offline.

## Scope boundary

This skill is the sentence- and media-context card component in the `learning-lab` learning flow. It accepts direct requests or handoffs with an exact sentence, source locator, target meaning, and existing language/deck choices. `ai-learning-review` handles durable concepts, rules, decisions, and searchable references across subjects. Both may use the same source for different retrieval goals; the same target should not be duplicated into both card types. Preview and import approval rules remain in effect.
