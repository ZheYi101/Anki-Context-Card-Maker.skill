# 适合长期复习的语境卡

## 先确定要练什么

默认卡正面显示目标词/表达与原句，训练在该语境下理解它的意义。它不独立证明会拼写、能脱离上下文说出来，或能只听音频辨认。需要这些能力时，优先用 `learning-lab` 的表达、听辨和换情境练习；用户明确要另一种卡型时，再选择相应格式，不自动批量生成正反向卡。

选用户想会用、经常遇到、正在混淆或有实际兴趣的目标。普通任务少量开始，允许 0 张；用户明确选择的词表按其范围处理，不因“少量”擅自丢弃。

先判断是否是用户真正想保留的表达，再判断题目是否能稳定检索；AI 自评通过不等于长期可用。实际复习中若只记住原句位置，应换一个真实语境检查理解；需要产出时另做表达任务，不以原卡答对代替。

## 一张卡一个意义目标

- 一次只检索这个表达在这句话里的意义或关键用法，不要求背所有词典义项。
- 保留能确定意义、语域或搭配的真实上下文。原句包含指代或缺少决定性前提时，先在学习中补足理解，或选更合适的真实实例；不要凭空编出上下文或解释。
- `definition` 给出本句适用的短释义，不能把所有词典释义拼起来。词典是支持材料，不能代替语境判断。
- `note` 只在有必要区分搭配、语气或误区时补一小段。更多例句和词典信息放在可展开的参考区，不让背面成为一页教程。
- 评分只看本句的核心意思，接受合理同义表达；不能把“没背出全部词典解释”当成失败。

例如，`bank` 在河边语境中的目标可以是“河岸”；金融机构、存储等义项保留在词典参考中。不要让用户在每次复习时背一整组彼此无关的义项。例子必须来自本次材料，示范造句不冒充原文。

## 导入前的预览检查

1. 词/表达的原文形式确实出现在选定原句中，原句能在来源中定位；时间窗与句子对应。辞书形与活用形、分离短语分别保存为 `term` 和 `surface`，不能为了匹配改写原句。
2. 正面没有提前显示翻译；必要语境足以确定本次检索目标，且没有无关的相邻句堆积。
3. 本句意义已经确认；`ready_for_import=false` 或 `quality_issues` 非空的内容仍是草稿。脚本跳过未匹配来源、缺少本句释义或任务要求的媒体尚未准备好的条目。`ready_for_import` 只表示这些前提齐备，不证明教学价值、意义判断或 `term` 与 `surface` 的语言学对应必然正确，也不证明学习效果。
4. 若任务要求音频或图片，它们确实可用且对应目标；缺失或待生成的资源如实列出，不把资源状态写成卡面诊断文字。
5. 更新已有实例沿用 `InstanceKey`；改进解释不重建卡片身份或重置调度。新句子可以形成另一个实例，但不是为了凑卡量。

未通过时修订或跳过；不强求把所有候选送进复习。预览获批后才实际写入。
